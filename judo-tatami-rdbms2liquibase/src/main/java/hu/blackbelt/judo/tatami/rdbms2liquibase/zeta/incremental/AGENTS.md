# AGENTS.md — `judo-tatami-rdbms2liquibase/src/main/java/hu/blackbelt/judo/tatami/rdbms2liquibase/zeta/incremental`

Modular Zeta incremental transformation phases generating Liquibase migration change sets.

| File | Purpose |
| --- | --- |
| `AbstractIncrementalSubTransformation.java` | Base class for incremental sub-transformations providing EMF model iteration over the incremental resource only (`all()` by kind, `allExact()` by exact type = ETL non-greedy rule source set), previous/new model membership (`previousModel()`, `newModel()`, `modelContains`, `modelContainsField`, `modelContainsIndex`: `model.eol`/`table.eol` uuid + identity semantics), review script resolution (`addReviewSqlFile`: `sqlFile.eol`), change set cache lookup, trace collection, and RDBMS field formatting. `abbreviate` uses `AbbreviateUtils` (ETL algorithm). See change: rdbms-incremental-without-epsilon. |
| `AfterIncrementalZetaTransformation.java` | Sub-transformation restoring foreign keys, unique constraints, indexes, and not-null constraints after incremental schema changes. Rule sources: exact types whose table is in the new model. See change: rdbms-incremental-without-epsilon. |
| `BackupDataSqlGenerator.java` | Java port of `generations/sql/main.egl` + `BackupTableData.egl`. `generate(RdbmsModel, dialect, prefix, tableNameMaxSize, Map<String,String>)` puts one `CREATE TABLE <prefix>_<abbreviated> AS (SELECT * FROM <table>)[ WITH DATA (hsqldb)];` script per deleted and modified table, key `<prefix lower>_<table lower>_data_<dialect>.sql` (modified: previous table). Backup table name of a modified table uses the current table name like the EGL. See change: rdbms-incremental-without-epsilon. |
| `BeforeIncrementalZetaTransformation.java` | Sub-transformation dropping indexes, unique constraints, foreign keys, and not-null constraints prior to applying schema modifications. Rule sources: exact types whose table is in the previous model. See change: rdbms-incremental-without-epsilon. |
| `DataUpdateAfterZetaTransformation.java` | Sub-transformation generating SQL script references for data migrations after schema updates (mandatory reviews, foreign key migrations, and new column data). Takes `reviewResolver` and shared `missingReviewScripts`: `SqlFile` only for an existing non-blank script, unknown scripts recorded with the ETL message, change set always created. See change: rdbms-incremental-without-epsilon. |
| `DataUpdateBeforeZetaTransformation.java` | Sub-transformation generating SQL script references for data migrations before schema updates (conversions, column type changes, and size reductions). Takes `reviewResolver` and shared `missingReviewScripts`: `SqlFile` only for an existing non-blank script, unknown scripts recorded with the ETL message, change set always created. See change: rdbms-incremental-without-epsilon. |
| `DbBackupZetaTransformation.java` | Sub-transformation creating backup SQL file definitions for modified or deleted tables prior to schema alteration. |
| `DbCheckupZetaTransformation.java` | Sub-transformation constructing Liquibase `PreConditions` checking table and column presence and verifying backup table absence. Rule sources: exact types in the previous model. See change: rdbms-incremental-without-epsilon. |
| `DbDropBackupZetaTransformation.java` | Sub-transformation verifying backup table existence and generating `DropTable` changes to clean up temporary backup tables post-migration. |
| `IncrementalZetaTransformation.java` | Core sub-transformation generating DDL operations for creating, dropping, and renaming tables and columns, as well as modifying column data types. |
