# AGENTS.md — `judo-tatami-rdbms2liquibase/src/main/java/hu/blackbelt/judo/tatami/rdbms2liquibase`

Workflow task, review resolvers, abbreviation utilities and ETL engine contract for RDBMS→Liquibase. Epsilon-free core; the ETL entry points (full and incremental) live in `judo-tatami-rdbms2liquibase-etl` and are reached through the `Rdbms2LiquibaseEtlEngine` / `Rdbms2LiquibaseIncrementalEtlEngine` SPI.

| File | Purpose |
| --- | --- |
| `AbbreviateUtils.java` | Abbreviates camelCase and underscored identifiers to target lengths by removing vowels and consonants according to English letter frequency tables. Exports `abbreviate(String, Integer, String)`. Requires `maxLength >= 1`. |
| `FileSystemReviewResolver.java` | Implements `ReviewResolver` over a directory root on disk. Exports `exists(String)` checking file presence and `resolve(String)` reading contents as UTF-8 string. |
| `Rdbms2LiquibaseEtlEngine.java` | Typed ETL engine contract. `execute(RdbmsModel, LiquibaseModel, dialect, Logger, createTrace, useCache, parallel)` → `void`; `ARTIFACT_COORDINATES = "hu.blackbelt.judo.tatami:judo-tatami-rdbms2liquibase-etl"`. Implemented by `-etl` module, resolved by `EtlEngineRegistry`. See change: split-etl-artifacts. |
| `Rdbms2LiquibaseIncrementalEtlEngine.java` | Typed incremental ETL engine contract. `execute(Rdbms2LiquibaseIncrementalParameter)` → `Rdbms2LiquibaseIncrementalResult`; `ARTIFACT_COORDINATES = "hu.blackbelt.judo.tatami:judo-tatami-rdbms2liquibase-etl"`. Implemented by `-etl` (`Rdbms2LiquibaseIncrementalEtlEngineImpl`), resolved by `EtlEngineRegistry`. See change: rdbms-incremental-without-epsilon. |
| `Rdbms2LiquibaseIncrementalParameter.java` | Immutable builder parameter (`rdbms2LiquibaseIncrementalParameter()`) of the incremental transformation: `incrementalRdbmsModel`, eight phase `LiquibaseModel`s, `dialect`, `backupPrefix` (default `BACKUP`), `tableNameMaxSize` (null → 30 oracle / 62), `reviewResolver`, `sqlScriptPath`, `sqlOutput`, `transformationMode` (default `ZETA`), ETL-only `log`, `parallel`. See change: rdbms-incremental-without-epsilon. |
| `Rdbms2LiquibaseIncrementalResult.java` | Result of both incremental engines. Getters `getBackupDataSqlFiles()` (file name → SQL), `getMissingReviewScripts()` (script name → message). Builder `rdbms2LiquibaseIncrementalResult()`. See change: rdbms-incremental-without-epsilon. |
| `Rdbms2LiquibaseIncrementalTransformation.java` | Entry point of the incremental RDBMS→Liquibase stage. `executeRdbms2LiquibaseIncrementalTransformation(parameter\|builder)`; `ZETA` (default, `isZeta()`) runs `Rdbms2LiquibaseIncrementalZetaTransformationV2` inline, otherwise `EtlEngineRegistry.require(Rdbms2LiquibaseIncrementalEtlEngine.class, ARTIFACT_COORDINATES)` (fails with the add-on coordinates, before any phase model is touched). Writes `backupDataSqlFiles` to `sqlOutput` for both modes. See change: rdbms-incremental-without-epsilon. |
| `Rdbms2LiquibaseWork.java` | Workflow task for full RDBMS→Liquibase; per-dialect models; mode ZETA by default. Zeta inline; ETL/DUAL via `EtlEngineRegistry.require(Rdbms2LiquibaseEtlEngine.class, ...)`. Ctor `(ctx, dialect)` only (script-root ctor removed). See change: split-etl-artifacts. |
| `ReviewResolver.java` | Interface for resolving external review SQL scripts by filename. Declares `exists(String name)` and `resolve(String name)`. |
