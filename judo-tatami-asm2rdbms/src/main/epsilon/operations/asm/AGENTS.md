# AGENTS.md — asm2rdbms/epsilon/operations/asm

EOL operations on the ASM (Ecore) source side: SQL naming, entity classification, reference shape.

| File | Purpose |
|---|---|
| `_importAsm.eol` | Include point for the ASM-side operation library — imports `attribute.eol`, `class.eol`, `namedElement.eol`, `package.eol`, `reference.eol`. Pulled in by `operations/_importAll.eol`; a new ASM operation file must be listed here to be visible to the ETL rules. |
| `attribute.eol` | `ASM!EAttribute` extensions. Exports `isPrimaryKey()` (true when the attribute equals `eContainingClass.primaryKeyAttribute()`), `fieldSqlName()`, `getAttributeFQName()` (delegates to injected `asmUtils`). `fieldSqlName()` reserves `DOMAIN_ID`/`DOMAIN_TYPE`/`DOMAIN_VERSION` for attributes named `id`/`type`/`version` ONLY while `columnPrefix` is blank; otherwise it emits `columnPrefix + abbreviate(sqlLongName(), columnNameMaxSize() - columnPrefix.length())` upper-cased. All operations `@cached` — results freeze after the first call, so mutating names mid-transformation yields stale SQL names. |
| `class.eol` | `ASM!EClass` extensions driving table/view naming and inheritance walks. Exports `classSqlName()`, `tableSqlName()`, `viewSqlName()`, `primaryKeyAttribute()`, `allSupertypesAttributes()`, `allDescandences()` (sic), `root()`, `getClassifierFQName()`, `isEntityType()`. `classSqlName()` prefixes the package SQL name unless program parameter `createSimpleName` is true; `tableSqlName()` applies `tablePrefix` and abbreviates to `tableNameMaxSize()`; `viewSqlName()` prefixes `V_` and reserves 2 chars. `primaryKeyAttribute()` picks the single attribute annotated `id=true` — a class with two such annotations resolves non-deterministically. `allDescandences()` recurses over all `ASM!EClass.all`, so it is O(n²) on the whole model. All `@cached`. |
| `namedElement.eol` | `ASM!ENamedElement` extensions producing the two base SQL name forms. Exports `sqlName()` and `sqlLongName()`. Both honour an explicit `shortName` extension annotation first, converting it via `toUpperSnakeCase()`; absent that, `sqlLongName()` always abbreviates to `sqlNameSize()` while `sqlName()` abbreviates to `sqlNameSize()` only when `createSimpleName` is set, else to the tighter `shortNameSize()`. Every table/column name in the RDBMS model bottoms out here, so changing the abbreviation strategy renames existing schemas. `@cached`. |
| `package.eol` | `ASM!EPackage` extensions. Exports `packageSqlName()` (delegates to `sqlName()`) and `root()`, which walks `eSuperPackage` to the topmost package. `root()` assumes an acyclic package containment — a cycle loops forever. `@cached`. |
| `reference.eol` | `ASM!EReference` extensions deciding foreign-key, inverse-FK and junction-table naming plus relation-kind dispatch. Exports `toString()`, `isForeign()`, `isMandatory()` (lower and upper bound both 1), `referenceIdentifierSqlName()`, `referenceInverseIdentifierSqlName()`, `referenceFkSqlName()`, `referenceUniFkSqlName()`, `referenceInvFkSqlName()`, `referenceManyToManyTableSqlName()`, `isFirst()`, `ruleMapping()`, `getReferenceFQName()`. FK column names reserve 3 chars for the `_ID` suffix against `columnNameMaxSize()`; junction-table names are built from BOTH ends when `eOpposite` exists, so both directions must agree — `isFirst()` breaks the tie by lexicographic name compare and returns true for a unidirectional reference. `ruleMapping()` resolves the `RDBMS!Rule` via `RDBMS!Rules.all.first.getRuleFromReference(self)` and requires exactly one `Rules` root in the RDBMS model. `isForeign()` calls `ownerReference()`, which this module does NOT define — it must come from the injected Java side. All `@cached`. |
