# AGENTS.md — asm2rdbms/zeta

Zeta-engine port of the ASM→RDBMS ETL, the default engine when `TransformationMode` is ZETA.

| File | Purpose |
|---|---|
| `Asm2RdbmsHelper.java` | Static facade for ID resolution, SQL naming, type filling and cache clearing shared by every Zeta rule class; 1:1 port of `epsilon/operations/`. → see `Asm2RdbmsHelper.java.AGENTS.md` |
| `Asm2RdbmsRuleNames.java` | Final, non-instantiable holder of the rule-name constants shared by the Zeta rules and trace consumers, one per ETL rule: `ROOT_PACKAGE_TO_MODEL`/`ROOT_PACKAGE_TO_CONFIGURATION` (values keep the ETL's `rootPackege` misspelling), the ten `ECLASS_TO_*` table and system-field rules, `EATTRIBUTE_TO_RDBMS_FIELD`/`_TABLE_VALUE_FIELD`/`_INDEX`, and the six `EREFERENCE_TO_*` FK and junction-table rules. Values must stay byte-identical to the ETL rule names — trace element IDs embed them, so renaming a value orphans existing traces. Zeta splits the ETL's single unidirectional junction FK rule into `..._FK_UNIDIRECTIONAL_1` and `..._2`. |
| `Asm2RdbmsZetaTransformation.java` | Runs the ASM→RDBMS lowering on the Zeta `TransformationRegistry` + `TransformationExecutor`. Lombok `@Builder` takes `@NonNull asmModel`, `@NonNull rdbmsModel`, `@NonNull dialect` plus optional naming knobs; `execute()` returns the native Zeta `TransformationTrace`. Constructor resolves dialect defaults — table/column/short/name sizes 30/30/6/28 for `oracle`, else 62/58/16/60 — and prefix defaults `T_`, `C_`, `FK_`, `FK_INV_`, `J_`, matching `Asm2Rdbms`. Indexes `TypeMappings` by `asmType` and grabs the first `Rules` root from the RDBMS resource set, throwing `IllegalStateException("Rules not found in RDBMS model...")` when the `mapping-<dialect>-rdbms.model` was not merged in first. Registers `PackageRules`, `ClassRules`, `AttributeRules`, `ReferenceRules` in ETL import order. Calls `Asm2RdbmsHelper.clearCaches()` before each run and forces `parallel(false)` — parallel execution NPEs in `postProcess` on large models. Context aliases resources `asm`/`rdbms` and exposes attributes `dialect`, `modelVersion`, the four `*Size` values, `createSimpleName`, the five prefixes, `asmUtils`, `typeMappings`, `rules` under exactly those keys. `postProcess` attaches each root package's `RdbmsModel` equivalent to the resource and then rewrites `sqlName` from every `NameMapping` matched on element `uuid` — the ETL `post` block's job. Nested `Asm2RdbmsModelProvider` enumerates sources via `AsmUtils`, so only ASM-resident elements are visible. |
| `CLAUDE.md` | `!! GENERATED` — `claude-mem` auto-writes the `<claude-mem-context>` block. Currently holds no activity. Not a source file; hand edits inside the tags are overwritten. |
