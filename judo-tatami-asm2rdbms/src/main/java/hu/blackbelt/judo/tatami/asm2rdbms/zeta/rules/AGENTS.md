# judo-tatami-asm2rdbms/src/main/java/hu/blackbelt/judo/tatami/asm2rdbms/zeta/rules

Zeta port of `asm2rdbms` ETL rule modules. Each class carries `@TransformationContext(source=..., target=...)` and exposes `TransformGuard` / `TransformFunction` factory methods discovered by `TransformationRegistry`. Rule names come from `Asm2RdbmsRuleNames`; shared logic from `Asm2RdbmsHelper`.

| File | Purpose |
|---|---|
| `AttributeRules.java` | Maps ASM `EAttribute` to RDBMS fields; port of `attribute.etl`. Exports guards `isAttributeInEntityType`, `isAttributeInEntityTypeNotDerived`, `isIdentifierAttributeInEntityType` and rules `eAttributeToRdbmsField` (`@Abstract`, base `RdbmsField`), `eAttributeToTableValueField` (`@Extends` base, emits `RdbmsValueField` and appends it to owner table), `eAttributeToIndex` (emits index for identifier attributes). `@Abstract` rule never runs standalone — child must call `ctx.executeParentRule(EATTRIBUTE_TO_RDBMS_FIELD, s)`. Needs `AsmUtils` and `Map<String,TypeMapping>` injected; default no-arg constructor exists only for registry instantiation, so registry-built instances resolve type mappings only after injection. |
| `ClassRules.java` | Maps entity `EClass` to `RdbmsTable` plus its tracking columns; port of `class.etl`. Exports guard `isEntityType` and rules `eClassToRdbmsTable`, `eClassToTableIdField`, `eClassToTableTypeField`, `eClassToTableVersionField`, `eClassToTableCreateUsernameField`, `eClassToTableCreateUserIdField`, `eClassToTableCreateTimestampField`, `eClassToTableUpdateUsernameField`, `eClassToTableUpdateUserIdField`, `eClassToTableUpdateTimestampField`. Every field rule resolves its owner via `ctx.equivalent(s, ECLASS_TO_RDBMS_TABLE)`, so `eClassToRdbmsTable` must have produced the table first or the lookup yields no table. Guard restricts all rules to entity `EClass` only. Needs `AsmUtils` + `TypeMapping` map injected. |
| `PackageRules.java` | Maps root ASM `EPackage` to the RDBMS model root; port of `package.etl`. Exports guard `isRootPackage` (true only when `getESuperPackage() == null`) and rules `rootPackegeToModel` (emits `RdbmsModel`), `rootPackegeToConfiguration` (emits `RdbmsConfiguration` and attaches it to the model's `configuration`). Configuration rule reads the default equivalent of the same `EPackage`, so it requires `rootPackegeToModel` to run first. Rule names keep the upstream ETL misspelling `rootPackege` — do not rename, `Asm2RdbmsRuleNames` constants and ETL parity depend on it. |
| `ReferenceRules.java` | Maps `EReference` to foreign keys and junction tables; port of `reference.etl`. Exports guards `isValidReference`, `needsForeignKey`, `needsInverseForeignKey`, `isValidReferenceForJunction`, `needsJunctionTableFirst`, `needsJunctionTableBidirectional`, `needsJunctionTableUnidirectional` and rules `eReferenceToRdbmsTableForeignKey`, `eReferenceToRdbmsTableInverseForeignKey`, `eReferenceToRdbmsJunctionTable` (`@Lazy`), `eReferenceToRdbmsJunctionTablePrimaryKey`, `eReferenceToRdbmsJunctionTableForeignKeyBidirectional`, `eReferenceToRdbmsJunctionTableForeignKeyUnidirectional`. `@Lazy` junction-table rule never fires from the main trace — it materialises only on `ctx.equivalent(s, EREFERENCE_TO_RDBMS_JUNCTION_TABLE)`; junction PK/FK rules depend on that call. Reads `rdbmsRules` `Rules`/`Rule` for name shortening, plus injected `AsmUtils` and `TypeMapping` map. |
