# AGENTS.md — asm2keycloak/zeta/rules

Declarative Zeta rule classes, one per ETL module of `asmToKeycloak.etl`.

| File | Purpose |
|---|---|
| `ClientRules.java` | Ports `client.etl`. `@TransformationContext(source = EClass.class, target = Client.class)`. Exports `createKeycloakClient() : TransformFunction<EClass, Client>` (rule `CREATE_KEYCLOAK_CLIENT`) and `createKeycloakClientClaim() : TransformFunction<EAttribute, AttributeBinding>` (rule `CREATE_KEYCLOAK_CLIENT_CLAIM`). Client rule skips non-actor types and actors without a non-blank `realm` extension annotation, returns null and warns when no `Realm` with that name exists in the target resource, else builds a `Client` via `KeycloakFactory.eINSTANCE` with `name` = `clientId` = classifier FQName dotted-to-dashed, `enabled`/`directAccessGrantsEnabled`/`publicClient` true, `bearerOnly` false, redirect URI `*`, and containment under `realm.getClients()`. Claim rule maps `claim` annotation `EMAIL`→`email`, `USERNAME`→`username`, escapes bare `email`/`username` to `_email`/`_username`, and attaches to `ctx.equivalent(actorType, Client.class)` — the claim is dropped from the model when the client equivalent is missing. Both read context attributes `asmUtils` and `keycloakResource` and set XMI ID `(asm/<elementId>)/<RuleName>` only when the target resource is an `XMLResource`; IDs are assigned after containment, so containment must be set first. Needs a public no-arg constructor for `TransformationRegistry`. |
| `RealmRules.java` | Ports the `pre` block of `realm.etl` as `@PreExecution public void createRealmsPreHook(TransformationContext ctx)`, `@TransformationContext(source = EClass.class, target = Realm.class)`. Collects actor types via `asmUtils.getAllActorTypes()`, groups by trimmed non-blank `realm` extension annotation into a `LinkedHashMap` keeping the FIRST actor per realm as the trace source, then creates one `Realm` per unique name with `id` = `realm` = the name, `enabled` and `loginWithEmailAllowed` true, adds it to the target resource contents and sets XMI ID `Realm/<name>` when the resource is an `XMLResource`. Must run before `ClientRules` — `createKeycloakClient` looks realms up by name and bails when absent. Reads context attributes `asmUtils` and `keycloakResource`; needs a public no-arg constructor for `TransformationRegistry`. |
