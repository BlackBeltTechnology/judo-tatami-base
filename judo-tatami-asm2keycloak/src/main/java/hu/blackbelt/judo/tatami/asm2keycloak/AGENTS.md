# AGENTS.md — asm2keycloak

ASM→Keycloak transformation entry points: ETL driver, workflow work unit, dual-engine trace.

| File | Purpose |
|---|---|
| `Asm2Keycloak.java` | Drives the ETL engine over `asmToKeycloak.etl`. Exports `executeAsm2KeycloakTransformation(Asm2KeycloakParameter)`, `calculateAsm2KeycloakTransformationScriptURI()`, builder `asm2KeycloakParameter()`, constant `SCRIPT_ROOT_TATAMI_ASM_2_KEYCLOAK = "tatami/asm2keycloak/transformations/"`. Wraps `AsmModel` and `KeycloakModel` as `WrappedEmfModelContext` entries, injects `AsmUtils` into the Epsilon context, runs an `EtlExecutionContext`, then extracts the ETL trace and returns an `Asm2KeycloakTransformationTrace`. `asmModel` and `keycloakModel` are `@NonNull` on the parameter; script URI resolution assumes the ETL scripts are on the classpath under the script root, MD5-keyed for cache reuse. |
| `Asm2KeycloakTransformationTrace.java` | Implements `TransformationTrace` over the ASM→Keycloak pair and carries EITHER the ETL trace (`Map<EObject, List<EObject>>`) or the Zeta trace (`zeta.transformation.core.TransformationTrace`) — the unused one stays null, so read through `isZetaTrace()`/`getZetaTrace()`/`getTransformationTrace()` rather than the fields. Exports `fromModelsAndTrace(...)`, `resolveAsm2KeycloakTrace(...)`, `createAsm2KeycloakTraceResource(...)`, `getAsm2KeycloakTrace(...)`, `save(...)`, `getSourceModelTypes()` = `[AsmModel]`, `getTargetModelType()` = `KeycloakModel`. Trace resource URIs use prefix `asm2keycloakTrace:` and postfix `asm2keycloak`; the constants are misnamed `ASM_2_RDBMS_*` though their values are the keycloak ones. Serialisation round-trip requires source/target models to be registered in the resolving `ResourceSet`, else trace entries resolve to null. |
| `Asm2KeycloakWork.java` | `AbstractTransformationWork` unit that plugs the transformation into a Tatami workflow. `execute()` pulls `AsmModel` from the `TransformationContext` (throws `IllegalArgumentException` when absent), reuses or builds a `KeycloakModel` named/versioned after the ASM model, then dispatches on `Asm2KeycloakWorkParameter.transformationMode` — Zeta path runs `Asm2KeycloakZetaTransformation`, ETL path runs `Asm2Keycloak.executeAsm2KeycloakTransformation`. Puts both the `KeycloakModel` and the resulting `Asm2KeycloakTransformationTrace` back into the context. `Asm2KeycloakWorkParameter` defaults `createTrace`/`parallel`/`useCache` true and `transformationMode` to `TransformationMode.fromSystemProperty()` (ZETA unless overridden). |
