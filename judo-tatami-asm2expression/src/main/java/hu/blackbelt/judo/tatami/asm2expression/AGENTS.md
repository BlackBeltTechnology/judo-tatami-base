# AGENTS.md — hu.blackbelt.judo.tatami.asm2expression (main)

| File | Purpose |
|---|---|
| `Asm2Expression.java` | Entry point extracting JQL expressions from an `AsmModel` into an `ExpressionModel`. Exports nested `@Builder` param class `Asm2ExpressionParameter` (`asm2ExpressionParameter()`; `asmModel` and `expressionModel` `@NonNull`, `measureModel` optional, `config` defaults to new `Asm2ExpressionConfiguration`) and static `executeAsm2Expression(...)` in builder and value form. Drives `AsmJqlExtractor` over ASM, measure and expression `ResourceSet`s and calls `extractExpressions()`. Null `measureModel` substitutes `MeasureModelResourceSupport.createMeasureResourceSet()`; expression model is mutated in place, not returned. Epsilon-free (unused `EmfUtils`/`ExecutionContext` imports dropped). See change: split-etl-artifacts. |
| `Asm2ExpressionConfiguration.java` | Config flag object for JQL expression building. Exports `isResolveOnlyCurrentLambdaScope()` / `setResolveOnlyCurrentLambdaScope(boolean)`, default `false` (was `true`), mapped onto `JqlExpressionBuilderConfig` by `Asm2Expression`. See change: persisted-query-model. |
| `Asm2ExpressionWork.java` | Workflow step wrapping `Asm2Expression` for the Tatami pipeline. Extends `AbstractTransformationWork`; exports `Asm2ExpressionWork(TransformationContext)`, `execute()`. Reads `AsmModel` (required), `MeasureModel` (optional) and `Asm2ExpressionConfiguration` (optional) from context; creates and registers an `ExpressionModel` named/versioned after the ASM model when absent. Missing `AsmModel` throws `IllegalArgumentException`. Registers EMF packages via `core.EmfPackages` (was Epsilon `EmfUtils`). Also puts an `ExpressionModelOrigin` into the context: `PRELOADED` when an `ExpressionModel` was already there, else `CREATED_IN_THIS_RUN`; recorded only after `executeAsm2Expression` succeeds (failed extraction leaves no origin). See change: split-etl-artifacts, persisted-query-model. |
| `ExpressionModelOrigin.java` | Enum `CREATED_IN_THIS_RUN` / `PRELOADED`, put into the `TransformationContext` by `Asm2ExpressionWork`. Downstream stages (asm2query) build only over a model created in the same run: a preloaded model keeps the bindings of whatever setting built it. See change: persisted-query-model. Put only after a successful extraction: a failed extraction leaves no origin, so the query stage skips. |
