# AGENTS.md — `judo-tatami-asm2query/src/main/java/hu/blackbelt/judo/tatami/asm2query`

Query builder, relocated from `judo-runtime-core-query` / `judo-runtime-core-expression` (see change: persisted-query-model).
Builds the logical query graph (`Select`, `SubSelect`, `Join`, `Filter`, `OrderBy`, `Feature`) over ASM, measure and
expression `ResourceSet`s, plus the `QueryModelInfo` index root that makes the model persistable. Epsilon-free
(no Epsilon, `mapper-api` or `judo-dispatcher-api` use here).

| File | Purpose |
| --- | --- |
| `Asm2Query.java` | Entry point; build part of the old `QueryFactory`. Exports `FORMAT_VERSION` (1), `TABLE_ALIAS_FORMAT`, `EXPOSED_ALIAS`, `DATA_ALIAS`, nested `@Builder Asm2QueryParameter` (`asm2QueryParameter()`: `asmResourceSet`, `measureResourceSet`, `expressionResourceSet`, `modelName` required except measure; optional `modelVersion`, `customJoinDefinitions`), static `executeAsm2Query(Asm2QueryParameter[.Builder])` and `executeAsm2Query(AsmModel, MeasureModel, ExpressionModel)` → `Asm2QueryResult`. Query resource URI is the logical `<modelName>-query.model`. Emits one `QueryModelInfo` root (keys, ordered relations, static sets, entity expressions incl. empty entries, counters, `formatVersion`, `modelName`; sorted by ASM name; stamps left unset for save). `orderedTransferRelations` is a concurrent set (filled from parallel streams). Fails with `IllegalStateException("Invalid query model")` when diagnostics fail. `Asm2QueryParameter.preserveExpressionModel` (default `false`): converters attach missing collection iterator variables to the expression model (`createIterator`); `true` removes them again after the build (Work sets it). See change: persisted-query-model. The constructor warms the lazy `EClass` feature tables single-threaded (`warmUpEClassCaches`) before the parallel build: EMF computes them unsynchronized and a half-built table was an NPE in `EClassImpl.getFeatureCount` under CPU contention. |
| `Asm2QueryConfiguration.java` | Optional context entry of `Asm2QueryWork`: `customJoinDefinitions` (`EReference` → `CustomJoinDefinition`, default empty, null-safe setter). No expression setting: the build uses the run's expression model. See change: persisted-query-model. |
| `Asm2QueryResult.java` | Immutable build result: `getQueryModel()`, `getIndex()` (`QueryIndex`, live counters), `getExpressionConverter()`, `getCustomJoinDefinitions()`, `getQueryModelInfo()` (single-root lookup). |
| `Asm2QueryWork.java` | Tatami-core `AbstractTransformationWork`. Reads `AsmModel`, `ExpressionModel` + `ExpressionModelOrigin`, optional `MeasureModel`, optional `Asm2QueryConfiguration`; puts the `QueryModel` into the context. Builds only if origin is `CREATED_IN_THIS_RUN`; absent expression model or origin absent/`PRELOADED` → WARN ("expression model not extracted in this run"), no `QueryModel`. Missing ASM → `IllegalArgumentException`. Builds with `preserveExpressionModel=true`: never modifies the `ExpressionModel`. No `EmfUtils`. Output predicate is not here (lives in each `WorkflowHelper`). See change: persisted-query-model. |
| `ConstantDecoder.java` | Package-private. Decodes `EJavaObject` hex (`Constant.value`) through a per-stream `ObjectInputFilter` allow-list (`java.lang` number/boolean/string, `BigInteger`, `BigDecimal`, `java.time.*`, primitive arrays; depth/array/reference/byte limits). Failure remembered in `getFailure()`. See change: persisted-query-model. |
| `Constants.java` | Query-builder numeric constants for measure handling. Exports `MEASURE_RATE_CALCULATION_SCALE` (30), `MEASURE_CONVERTING_PRECISION` (100), `MEASURE_CONVERTING_SCALE` (15). `MEASURE_RATE_CALCULATION_SCALE` must stay greater than `MEASURE_CONVERTING_SCALE`. |
| `Context.java` | `@Builder @Getter` mutable query-build state (`node`, `createdQueryObjects`, `variables` `TreeMap`, `sourceCounter`/`targetCounter`); exports `addFeature(Feature)`, `clone()`, `clone(String, Node)`. → see `Context.java.AGENTS.md` |
| `CustomJoinDefinition.java` | Immutable `@Builder @Getter` value object of a custom join: `sourceIdParameterName`, `sourceIdSetParameterName`, `navigationSql` (raw trusted SQL). Own value type of `Asm2Query`; runtime-core keeps its own class of the same shape. |
| `DataExpressionConverter.java` | Wires `JoinFactory` + `FeatureFactory` + `AsmModelAdapter` over ASM and measure resource sets (empty measure set when null). Exports `dataExpressionToFeature(DataExpression, Context, Target, EAttribute)`, `getModelAdapter()`, `getJoinFactory()`, `getFeatureFactory()`. Same wiring for a built and a restored model (the runtime converts expressions per request). |
| `EntityTypeExpressions.java` | Entity-side binding maps: `@Builder` over `@NonNull entityType`, `getterAttributeExpressions` (`EAttribute` → `DataExpression`), `getterReferenceExpressions` (`EReference` → `ReferenceExpression`), both final `ConcurrentHashMap`s mutated in place. |
| `FeatureFactory.java` | Registry mapping expression types to `ExpressionToFeatureConverter`s; exports `convert(Expression, Context, FeatureTargetMapping)`. Constructor `(JoinFactory, AsmModelAdapter, MeasureProvider)`; `Coercer` dropped. → see `FeatureFactory.java.AGENTS.md` `startTrackingCreatedIterators()` / `iteratorCreated(CollectionExpression)` / `releaseCreatedIterators()` undo the iterator variables created by `ExpressionToFeatureConverter.getCollectionIterator` during a build. See change: persisted-query-model. |
| `JoinFactory.java` | Abstract factory unfolding navigation chains into `Join`/`Filter`/`OrderBy`/`SubSelect` nodes; exports `convertNavigationToJoins(Context, Node, ReferenceExpression, boolean)` → `PathEnds`. → see `JoinFactory.java.AGENTS.md` |
| `MappedTransferObjectTypeBindings.java` | Node of the mapped transfer object expression tree. `@Builder` pins `@NonNull entityType` + `@NonNull transferObjectType`; getter/setter maps, child `references`, `@Setter filter` `LogicalExpression`. |
| `PersistedQueryModel.java` | Locator: logical `getName()` plus exactly one `StreamSupplier` (`open()` throws `IOException`). `openStream()` is the only call into the supplier; creation reads nothing. Same type for every container. |
| `QueryIndex.java` | Runtime index over the query model: `getQuery(EClass)`, `getNavigation(EReference)`, `getDataQuery(EAttribute)`, `isOrdered`, `isStaticAttribute` / `isStaticReference` = `getMappedX(f).map(set::contains).orElse(true)`, `getEntityTypeExpressionsMap()`, live `getNextSourceIndex()` / `getNextTargetIndex()`, key-set getters. Concurrent types. `restore(ResourceSet, QueryModel)` / `restore(AsmUtils, QueryModelInfo)` rebuild it; `getQueryModelInfo(Resource)` fails on 0 or 2+ roots; restore fails on unset / foreign `formatVersion` (unset stamp = mismatch), null or proxy entries, non-`DataExpression` / `ReferenceExpression` getters. |
| `QueryModelPersistence.java` | → see `QueryModelPersistence.java.AGENTS.md` — save (`save(SaveArguments)`: URI rewrite, counted reference guard, stamps, digests) and load (`load(name, stream, asmResource, expressionResource)`: logical URI, `uriResourceMap`, `resolveAll`, unresolved count, constant allow-list), `checkStamps`, `generatorIdentity`, digest helpers. |
| `TransferObjectTypeBindingsCollector.java` | → see `TransferObjectTypeBindingsCollector.java.AGENTS.md` — walks ASM transfer object types, collects expression bindings through a binding index, exposes static sets. |
| `UnmappedTransferObjectTypeBindings.java` | Binding holder for transfer object types without mapped entity: `dataExpressions`, `navigationExpressions` from GETTER-role bindings of derived features. |
