# judo-tatami-psm2asm/src/main/epsilon/transformations/asm/modules

ETL rule modules imported by `../psmToAsm.etl`. Every module reads `JUDOPSM!` elements and emits `ASM!` Ecore elements. Shared query operations come from `../utils/_importUtils.eol`; `namespace.etl` supplies the `NamespaceToPackage` container lookup and the `@abstract CreateDocumentationAnnotation` base rule that most documentation rules extend.

Cross-module invariants: every emitted element gets a synthetic id `"(psm/" + s.getId() + ")/<RuleSuffix>"` — ids must stay unique or the ASM resource fails to load. Annotation `source` URIs come from `asmUtils.getAnnotationUri(<name>)`, never literal strings. Qualified names come from `psmUtils.namespaceElementToString(...)`, with `::` replaced by `.` where ASM expects dotted names.

| File | Purpose |
|---|---|
| `actor.etl` | Maps actor-flavoured `JUDOPSM!TransferObjectType` to ASM annotations on the already-created `EClass`. Rules `CreateActorAnnotation` (guard `s.actorType.isDefined()`; emits `actor` annotation with `name`, optional `realm` details), `CreateActorTypeAnnotation` (guard kind-of `AbstractActorType`; emits `actorType` annotation with `value=true`, plus `managed` for `MappedActorType` and optional `kind`), `CreateRealmTypeAnnotation`, `CreateDocumentationAnnotationForActorType` (extends `CreateDocumentationAnnotation`). All rules are `@greedy` and attach to `s.asmEquivalent()` — the transfer-object class rules in `transferObject.etl` must have produced the equivalent first. Imports `operation.etl` and `namespace.etl`. |
| `data.etl` | Maps the PSM entity layer to ASM classes, attributes and references. Emits `EClass` per `EntityType` (`CreateEntityClass`, carries `abstract`, `eSuperTypes` from `superEntityTypes`, attaches to the containing namespace package), `EAttribute` per `Attribute` (`CreateAttribute`), `EReference` per `Relation` via `@abstract CreateRelation` specialised by `CreateAssociationEndRelation` and `CreateContainmentRelation`. Annotation rules add `entity`, `defaultRepresentation`, identifier, unmapped-default-only and documentation markers; constraint rules form an `@abstract AddAttributeConstraints` hierarchy (`AddStringAttributeConstraints`, `AddCustomAttributeConstraints`, `@abstract AddAbstractNumericAttributeConstraints` → `AddNumericAttributeConstraints` / `AddMeasuredAttributeConstraints`). `@abstract CreateSequence` is specialised by `CreateNamespaceSequence` and `CreateEntitySequence`. Annotation rules resolve their owner via the named equivalent `s.equivalent("CreateEntityClass")` — renaming `CreateEntityClass` silently breaks every one of them. |
| `derived.etl` | Maps PSM derived members (`PrimitiveAccessor`, `ReferenceAccessor`) to ASM `EAttribute`/`EReference` plus their JQL expression annotations. Exports `@abstract CreatePrimitiveAccessor` → `CreateDataProperty` (`DataProperty` → `EAttribute`), `@abstract CreateReferenceAccessor` → `CreateNavigationProperty` (`NavigationProperty` → `EReference`), plus `CreatePrimitiveAccessorExpressionAnnotation` and `CreateReferenceAccessorExpressionAnnotation` carrying the getter expression. Constraint hierarchy mirrors `data.etl`: `@abstract AddPrimitiveAccessorConstraints` → string / custom / `@abstract AddAbstractNumericPrimitiveAccessorConstraints` → numeric / measured. Every accessor rule guards `not s.isKindOf(JUDOPSM!StaticData)` — static accessors belong to `static.etl` and double-transform if the guard is dropped. |
| `namespace.etl` | Maps the PSM namespace tree to the ASM package tree and hosts the shared documentation base rule. Exports `@abstract NamespaceToPackage` → `ModelToPackage` (`JUDOPSM!Model` → root `EPackage`) and `PackageToPackage` (nested `EPackage`), `ModelToPackageVersion` (emits version annotation on the model package), and `@abstract CreateDocumentationAnnotation` (`NamedElement` → documentation `EAnnotation`). Every other module imports this file for `CreateDocumentationAnnotation`; changing its target type or id scheme breaks all extending rules. |
| `operation.etl` | Maps PSM operations to ASM `EOperation`/`EParameter` plus behaviour, stateful and permission annotations (528 lines). → see `operation.etl.AGENTS.md` |
| `static.etl` | Maps `JUDOPSM!StaticData` and `JUDOPSM!StaticNavigation` to synthetic unmapped transfer-object `EClass`es holding a single query member. `CreateUnmappedTransferObjectForStaticData` + `CreateStaticQueryAttribute` emit class + `EAttribute`; `CreateUnmappedTransferObjectForStaticNavigation` + `CreateStaticQueryNavigation` emit class + `EReference`. Supporting annotation rules mark transfer-object type, static query, parameterized transfer members, and the data/navigation expression bindings (`CreateDataReferenceBindingForStaticData`, `CreateNavigationReferenceBindingForStaticNavigation`). All rules `@greedy`. Static accessors are excluded from `derived.etl` by its `not s.isKindOf(JUDOPSM!StaticData)` guard — the two modules must stay in sync. |
| `transferObject.etl` | Maps the PSM transfer-object layer to ASM classes, attributes, references and binding annotations (695 lines). → see `transferObject.etl.AGENTS.md` |
| `type.etl` | Maps PSM primitive and enumeration types to ASM `EDataType`/`EEnum` classifiers. Exports `CreateEnumeration` (`EnumerationType` → `EEnum` with literals) and one rule per primitive: `CreateStringType`, `CreateIntegerType`, `CreateDecimalType`, `CreateBooleanType`, `CreatePasswordType`, `CreateBinaryType`, `CreateXMLType`, `CreateDateType`, `CreateTimestampType`, `CreateTimeType`, `CreateCustomType`, plus `CreateMeasuredAnnotationOfIntegerType` attaching measure metadata to measured integers. All rules `@greedy`. Only module importing nothing but `../utils/_importUtils.eol` — it has no dependency on `namespace.etl`, so type classifiers are attached by their own container lookup. |
