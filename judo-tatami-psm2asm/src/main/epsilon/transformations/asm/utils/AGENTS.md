# judo-tatami-psm2asm/src/main/epsilon/transformations/asm/utils

EOL query operations shared by the PSM→ASM rule modules. Core idiom: each PSM type gets an `asmEquivalent()` operation that resolves the ASM element produced by one *named* ETL rule, so rule modules never spell the rule name inline. Renaming an ETL rule in `../modules/` requires the matching rename here or `asmEquivalent()` returns undefined.

| File | Purpose |
|---|---|
| `_importUtils.eol` | Single import aggregator for the EOL helper set. Imports `derived.eol`, `operation.eol`, `package.eol`, `transferObject.eol`, `type.eol`, `id.eol`. Every module in `../modules/` imports this file only — add a new helper file here or rule modules will not see it. Order is not significant; there is no `data.eol`, so entity/attribute/relation rules resolve equivalents by explicit `s.equivalent("<Rule>")` calls instead. |
| `derived.eol` | Resolves ASM equivalents for PSM derived and static members. Exports `@cached asmEquivalent()` on `DataProperty` → `EAttribute` (`CreateDataProperty`), `NavigationProperty` → `EReference` (`CreateNavigationProperty`), `StaticData` → `EAttribute` (`CreateStaticQueryAttribute`), `StaticNavigation` → `EReference` (`CreateStaticQueryNavigation`). Static members resolve to rules in `../modules/static.etl`, derived ones to `../modules/derived.etl` — the split must match `derived.etl`'s `not s.isKindOf(JUDOPSM!StaticData)` guards. |
| `id.eol` | Bridges synthetic element ids to the EMF resource. Exports `Any setId(id : String)` and `Any getId() : String`, both delegating to `self.eResource.setId/getId`. Every ETL rule builds target ids as `"(psm/" + s.getId() + ")/<RuleSuffix>"` through these operations; the underlying resource must support id assignment (`XMIResource`-style) or `setId` fails. Declared on `Any`, so calling `getId()` on an element never registered returns undefined rather than raising. |
| `operation.eol` | Resolves ASM equivalents and parameter roles for PSM operations. Exports `@cached asmEquivalent()` on `BoundOperation` (`CreateBoundOperation`), `BoundTransferOperation` (`CreateBoundTransferOperation`), `UnboundOperation` (`CreateUnboundOperation`), all → `EOperation`; plus `@cached` role predicates on `Parameter`: `isInput()`, `isOutput()`, `isFault()`, each comparing against the containing `OperationDeclaration`'s `input`/`output`/`faults`. Predicates read `self.eContainer` directly — a detached `Parameter` yields false, not an error. |
| `package.eol` | Resolves the ASM package for a PSM namespace. Exports `@cached asmEquivalent()` on `Model` → `EPackage` (`ModelToPackage`) and `Package` → `EPackage` (`PackageToPackage`). `NamespaceToPackage` is `@abstract` in `../modules/namespace.etl` and deliberately has no equivalent operation here — resolving it directly returns nothing. |
| `transferObject.eol` | Resolves ASM equivalents for transfer-object elements and classifies metadata/range types. Exports `@cached asmEquivalent()` on `MappedTransferObjectType` → `EClass` (`CreateMappedTransferObject`), `UnmappedTransferObjectType` → `EClass` (`CreateUnmappedTransferObject`), `TransferObjectRelation` → `EReference` (`CreateTransferObjectRelation`), `TransferAttribute` → `EAttribute` (`CreateTransferObjectAttribute`); plus `TransferObjectType isMetadataType()` (true when some `TransferOperation` with `behaviourType == GET_METADATA` outputs this type or a relation target of it) and `isGetRangeInputType()` (true when some `TransferOperation` with `behaviourType == GET_RANGE` takes this type as input). Both predicates scan `JUDOPSM!TransferOperation.all()` on every call: their annotations read `@cahced`, a misspelling of `@cached`, so Epsilon ignores them and the scan is not memoised — O(operations) per invocation. |
| `type.eol` | Resolves the ASM `EDataType` for a PSM `Primitive`. Exports `@cached asmEquivalent()` dispatching on `isString()`, `isInteger()`, `isDecimal()`, `isBoolean()`, kind-of `EnumerationType`, `isDate()`, `isTimestamp()`, `isTime()`, kind-of `BinaryType`, falling through to `CreateCustomType`. Dispatch order is load-bearing: `EnumerationType` is checked after the numeric predicates, and the final `else` swallows any unrecognised primitive into `CreateCustomType` rather than failing. `PasswordType` and `XMLType` have rules in `../modules/type.etl` but no branch here — they land in the `CreateCustomType` fallback. |
