# judo-tatami-psm2asm/src/main/java/hu/blackbelt/judo/tatami/psm2asm/zeta

Zeta (native Java) engine for PSM→ASM, the alternative to the Epsilon ETL scripts under `src/main/epsilon/transformations/asm/`. Rule classes live in `rules/`; this package holds the driver, the shared static helpers, and the rule-name constants that keep both engines trace-compatible.

| File | Purpose |
|---|---|
| `CLAUDE.md` | `!! GENERATED` — claude-mem context stub. Contains only an empty `<claude-mem-context>` block with a "*No recent activity*" placeholder. Not source, not documentation of this package; carries no transformation contract. Regenerated by the claude-mem tool, so hand edits inside the tags are lost. |
| `Psm2AsmHelper.java` | Static helper surface for every rule class: id generation, qualified names, annotation URIs, EMF containment mutators, type resolution, plus three global static caches reset by `clearCaches()` (778 lines). → see `Psm2AsmHelper.java.AGENTS.md` |
| `Psm2AsmRuleNames.java` | 179 `public static final String` rule-name constants mirroring the ETL rule names, grouped by source `.etl` module; values are the `ctx.equivalent` lookup keys (641 lines). → see `Psm2AsmRuleNames.java.AGENTS.md` |
| `Psm2AsmZetaTransformation.java` | Drives the Zeta PSM→ASM run. `@Builder` constructor takes `@NonNull psmModel`, `@NonNull asmModel`, `@NonNull modelName` and optional `nsURI` / `nsPrefix` defaulting to `http://blackbelt.hu/judo/<modelName>` and `runtime<modelName>`. Exports `execute()` → Zeta `TransformationTrace` in six logged phases: `Psm2AsmHelper.clearCaches()`, build `TransformationRegistry`, build `TransformationContext`, build `TransformationExecutor`, `executor.transform()`, `postProcess(context)`. Registry registration order is load-bearing — `NamespaceRules`, `TypeRules`, `DataRules`, `TransferObjectRules`, `DerivedRules`, `StaticRules`, `OperationRules`, `BoundTransferOperationAnnotationRules`, `ActorRules`; `BoundTransferOperationAnnotationRules` must follow `OperationRules`. Executor runs `parallel(false)` with `ExecutionStrategy.RULE_BY_RULE` for ETL parity (every rule sees all elements before the next rule runs). Context sets `targetPackage = EcorePackage.eINSTANCE`, `useStructuredIds(true)`, `etlCompatibilityMode(true)`, registers resources under aliases `psm` / `asm`, sets `preferredSourceAlias("psm")` to match ETL id format, and publishes attributes `modelName`, `nsURI`, `nsPrefix`, `getRangeInputTypes`. `autoAddRootElements` is deliberately left false — root packages are attached in `postProcess` step 1 so pending XMI ids propagate to children; enabling it breaks id assignment. `postProcess` then sets `EOpposite` for paired `AssociationEnd`s, resolves `TransferObjectRelation` target `EType`s, and wires reference-class inheritance — each step is guarded to only fill values still null, so it never overwrites what a rule already set. Metrics collection is off unless system property `judo.zeta.transformation.metrics` is true. Also exports the `ModelProvider` helpers `getAllContents`, `getName`, `getTypeName`. |
