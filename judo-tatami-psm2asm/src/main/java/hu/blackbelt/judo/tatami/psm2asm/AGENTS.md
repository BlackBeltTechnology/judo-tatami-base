# judo-tatami-psm2asm/src/main/java/hu/blackbelt/judo/tatami/psm2asm

Java entry points of the PSM→ASM lowering. Two engines behind one work: Epsilon ETL (scripts in `../../../../../../epsilon/transformations/asm/`) and Zeta (`zeta/`). Trace shape is shared.

| File | Purpose |
|---|---|
| `Psm2Asm.java` | Runs the ETL PSM→ASM transformation. Exports `Psm2AsmParameter` (`@Builder(builderMethodName="psm2AsmParameter")`; `@NonNull psmModel`, `@NonNull asmModel`, `scriptUri` defaulting to `calculatePsm2AsmTransformationScriptURI()`, `log`, `createTrace=false`, `parallel=true`, `useCache=true`), `executePsm2AsmTransformation(...)` returning `Psm2AsmTransformationTrace`, `calculatePsm2AsmTransformationScriptURI()`, and constants `SCRIPT_ROOT_TATAMI_PSM_2_ASM = "tatami/psm2asm/transformations/asm/"`, `HTTP_BLACKBELT_HU_JUDO_META_EXTENDED_METADATA`. Registers the PSM resource under Epsilon model name `JUDOPSM` and the ASM resource under `ASM` — ETL rules address those names, renaming breaks every rule. Injects native tools `asmUtils` (`AsmUtils`) and `psmUtils` (`PsmUtils`); `psmToAsm.etl`'s post block calls `asmUtils.enrichWithAnnotations()`, so both injections are mandatory. Passes program parameters `modelName`, `nsURI` (`http://blackbelt.hu/judo/<modelName>`), `nsPrefix` (`runtime<modelName>`), `extendedMetadataURI`. Model validation is disabled on both contexts (`validateModel(false)`). Trace map stays empty unless `createTrace` is true. When the caller supplies no `log`, a `BufferedSlf4jLogger` is created and closed in `finally`; a caller-supplied logger is never closed. `calculatePsm2AsmTransformationScriptURI()` branches on the code-source location ending `.jar` vs. starting `jar:bundle:` vs. plain directory — OSGi bundles depend on the `jar:bundle:` branch. |
| `Psm2AsmTransformationTrace.java` | Carries the PSM→ASM trace and (de)serialises it; implements `TransformationTrace`. Exports `psm2AsmTransformationTraceBuilder()`, `getSourceModelTypes`/`getSourceModels`/`getSourceModel`/`getSourceResourceSet`/`getSourceURI`, `getTargetModelType`/`getTargetModel`/`getTargetResourceSet`/`getTargetURI`, `getTransformationTrace`, `getZetaTrace`, `isZetaTrace`, `createPsm2AsmTraceResource`, `resolvePsm2AsmTrace`, `getPsm2AsmTrace`, `getPsm2AsmTraceResource`, `fromModelsAndTrace`, `save`, plus constants `PSM_2_ASM_URI_POSTFIX = "psm2asm"` and `PSM_2_ASM_TRACE_URI_PREFIX = "psm2asmTrace:"`. Holds exactly one of two mutually exclusive trace fields: `trace` (`Map<EObject,List<EObject>>`, ETL) or `zetaTrace` (Zeta `TransformationTrace`); `isZetaTrace()` selects which. Setting both, or neither, yields an inconsistent trace — builders must pick one. `psmModel` and `asmModel` are `@NonNull`. |
| `Psm2AsmWork.java` | Workflow work driving PSM→ASM with engine selection. Extends `AbstractTransformationWork`; exports `Psm2AsmWorkParameter` (`createTrace=false`, `parallel=true`, `useCache=true`, `transformationMode` defaulting to `TransformationMode.fromSystemProperty()`) and two constructors — one taking an explicit script-root `URI`, one defaulting to `Psm2Asm.calculatePsm2AsmTransformationScriptURI()`. `execute()` requires `PsmModel` in `TransformationContext` (missing one throws `IllegalArgumentException`), creates an empty `AsmModel` via `buildAsmModel()` when absent, puts it back into the context *before* transforming, calls `EmfUtils.addEmfPackagesToResourceSet` on the ASM resource set, then branches on `workParam.transformationMode.isZeta()` to `Psm2AsmZetaTransformation` or to `Psm2Asm.executePsm2AsmTransformation`. Zeta path ignores `createTrace`, `parallel` and `useCache` — those parameters only affect the ETL path. Result `Psm2AsmTransformationTrace` is put into the context; default engine is whatever the system property resolves to, so engine choice is ambient unless a `Psm2AsmWorkParameter` is placed in the context. |
