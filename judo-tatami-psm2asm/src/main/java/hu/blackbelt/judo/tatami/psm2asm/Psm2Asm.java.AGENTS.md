# `Psm2Asm.java`

Runs the ETL PSM→ASM transformation. Exports `Psm2AsmParameter` (`@Builder(builderMethodName="psm2AsmParameter")`; `@NonNull psmModel`, `@NonNull asmModel`, `scriptUri` defaulting to `calculatePsm2AsmTransformationScriptURI()`, `log`, `createTrace=false`, `parallel=true`, `useCache=true`), `executePsm2AsmTransformation(...)` returning `Psm2AsmTransformationTrace`, `calculatePsm2AsmTransformationScriptURI()`, and constants `SCRIPT_ROOT_TATAMI_PSM_2_ASM = "tatami/psm2asm/transformations/asm/"`, `HTTP_BLACKBELT_HU_JUDO_META_EXTENDED_METADATA`.
Registers the PSM resource under Epsilon model name `JUDOPSM` and the ASM resource under `ASM` — ETL rules address those names, renaming breaks every rule. Injects native tools `asmUtils` (`AsmUtils`) and `psmUtils` (`PsmUtils`); `psmToAsm.etl`'s post block calls `asmUtils.enrichWithAnnotations()`, so both injections are mandatory.
Passes program parameters `modelName`, `nsURI` (`http://blackbelt.hu/judo/<modelName>`), `nsPrefix` (`runtime<modelName>`), `extendedMetadataURI`. Model validation is disabled on both contexts (`validateModel(false)`). Trace map stays empty unless `createTrace` is true.
When the caller supplies no `log`, a `BufferedSlf4jLogger` is created and closed in `finally`; a caller-supplied logger is never closed. `calculatePsm2AsmTransformationScriptURI()` branches on the code-source location ending `.jar` vs. starting `jar:bundle:` vs. plain directory — OSGi bundles depend on the `jar:bundle:` branch.
