# `Psm2AsmTransformationSerivce.java`

Runs ETL PSM→ASM transformation inside OSGi, publishes its trace. `@Component(immediate = true, service = Psm2AsmTransformationSerivce.class)`; exports `activate(BundleContext)`, `install(PsmModel)` → `AsmModel`, `uninstall(PsmModel)`.
`install` builds empty `AsmModel` at URI `asm:<psmModelName>.asm`, resolves script root from bundle entry `/tatami/psm2asm/transformations/asm/psmToAsm.etl` (entry must be packaged in bundle or `getEntry` returns null and `install` throws NPE), then calls `Psm2Asm.executePsm2AsmTransformation`. Resulting `Psm2AsmTransformationTrace` registered as `TransformationTrace` service with empty properties — consumers cannot filter by model name. `createTrace` left at default `false`, so registered trace carries no ETL trace map. Buffered ETL log emitted yellow on success, red on failure, exception rethrown. `psm2AsmTransformationTraceRegistration` keyed by `PsmModel` identity in plain `HashMap`; `uninstall` on unknown model only logs error.
