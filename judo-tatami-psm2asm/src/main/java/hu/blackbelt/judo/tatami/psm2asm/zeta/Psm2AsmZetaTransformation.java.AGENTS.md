# `Psm2AsmZetaTransformation.java`

Drives Zeta PSM→ASM run. `@Builder` constructor takes `@NonNull psmModel`, `@NonNull asmModel`, `@NonNull modelName` and optional `nsURI` / `nsPrefix` defaulting to `http://blackbelt.hu/judo/<modelName>` and `runtime<modelName>`. Exports `execute()` → Zeta `TransformationTrace` in six logged phases: `Psm2AsmHelper.clearCaches()`, build `TransformationRegistry`, build `TransformationContext`, build `TransformationExecutor`, `executor.transform()`, `postProcess(context)`.
Registry registration order load-bearing — `NamespaceRules`, `TypeRules`, `DataRules`, `TransferObjectRules`, `DerivedRules`, `StaticRules`, `OperationRules`, `BoundTransferOperationAnnotationRules`, `ActorRules`; `BoundTransferOperationAnnotationRules` must follow `OperationRules`. Executor runs `parallel(false)` with `ExecutionStrategy.RULE_BY_RULE` for ETL parity (every rule sees all elements before next rule runs).
Context sets `targetPackage = EcorePackage.eINSTANCE`, `useStructuredIds(true)`, `etlCompatibilityMode(true)`, registers resources under aliases `psm` / `asm`, sets `preferredSourceAlias("psm")` to match ETL id format, publishes attributes `modelName`, `nsURI`, `nsPrefix`, `getRangeInputTypes`. `autoAddRootElements` deliberately left false — root packages attached in `postProcess` step 1 so pending XMI ids propagate to children; enabling it breaks id assignment.
`postProcess` sets `EOpposite` for paired `AssociationEnd`s, resolves `TransferObjectRelation` target `EType`s, wires reference-class inheritance — each step guarded to only fill values still null, so never overwrites what a rule already set. Metrics off unless system property `judo.zeta.transformation.metrics` true. Also exports `ModelProvider` helpers `getAllContents`, `getName`, `getTypeName`.
